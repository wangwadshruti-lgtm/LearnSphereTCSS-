# LearnSphere — Advanced Learning Platform

A polished, responsive learning dashboard built with React, Vite, Tailwind CSS, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Highlights

- Premium responsive dashboard, course catalogue, progress and category views
- Accessible course-details dialog: focus management, escape and backdrop close
- Sticky navigation and keyboard-accessible notification center
- Reusable components, local dummy data, and mobile-first Tailwind styling

## Structure

`src/components` holds reusable UI; `src/data` has content fixtures; `src/hooks` contains reusable behaviors.

## Accessibility

Semantic controls, visible keyboard focus, labeled progress bars, appropriate dialog semantics, and high-contrast design are included throughout.
